
# 📊 Search Engine Analysis

A data analysis project that explores search engine data and uncovers insights about keyword performance and trends using Python and Jupyter Notebook.

---

## 🧠 Overview

This repository contains:
- A Jupyter Notebook for analyzing search engine data  
- CSV files containing raw and processed datasets  
- A PowerPoint presentation summarizing the findings  

The objective of this project is to analyze search behavior and extract meaningful insights that can help improve search performance.

## 📌 Requirements

To run this project, you need:

- Python 3.7 or above  
- Jupyter Notebook / Jupyter Lab  

Required libraries:
pandas
numpy
matplotlib
seaborn
notebook


Install them using:

```bash
pip install pandas numpy matplotlib seaborn notebook

```
🚀 How to Run

1. Clone the repository:
```
git clone https://github.com/niyatiUnhex/search_engine_analysis.git
cd search_engine_analysis
```
2. Open the notebook:

jupyter notebook search_engine_analytics.ipynb
